# Sentinel-Chain-AI-Cyber-Defense
Sentinel Chain is an enterprise-grade cybersecurity platform that collects logs, detects threats using AI, and stores tamper-proof incident evidence on Hyperledger Fabric.
# Sentinel Chain

AI-Powered Autonomous Cyber Defense Platform

## Features

- Real-Time Log Collection
- AI Threat Detection
- User Behavior Analytics
- Graph-based Attack Prediction
- Hyperledger Fabric Integration
- Tamper-Proof Incident Storage
- Interactive Security Dashboard
